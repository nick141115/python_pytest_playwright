# Pre-commit

1.	**Установка pre-commit:**

```sh
pip install pre-commit
```

2.	**Конфигурационный файл – `.pre-commit-config.yaml` в корне проекта**

3.	**Установить Git-хуки**

Находясь в корне проекта:

```sh
pre-commit install
```
