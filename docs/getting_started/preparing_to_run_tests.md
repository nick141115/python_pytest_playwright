# Подготовка к запуску тестов

Перед запуском тестов необходимо убедиться, что установлен браузер, поддерживаемый Playwright.
Запуск команды без аргументов установит браузеры по умолчанию.

```sh
playwright install
```

Вы также можете установить определенные браузеры, указав соответствующий аргумент:

```sh
playwright install webkit
```
