# Запуск тестов

Запуск всех доступных тестов, расположенных в корневой папке, осуществляется с помощью команды:

```sh
pytest .
```

Если вам нужно запустить определенный тест, напишите "pytest", указывая конкретный тестовый файл, например:

```sh
pytest tests/one_workload/test_example.py
```

или:

```sh
pytest tests/default/test_another_example.py
```

---

Все действия далее производятся в каталоге с проектом в консоли или в IDE. 

Перед запуском тестов необходимо [настроить окружение](environment.md)!

## Запуск с консоли

### Запуск тестов в модуле

```plaintext
pytest test_module.py
```

### Запуск тестов в каталоге

```plaintext
pytest tests/
```

### Запуск тестов через выражение

```plaintext
pytest -k "MyClass and not method"
```

### Запуск тестов по идентификаторам

Каждому собранному тесту присваивается уникальный идентификатор узла, который состоит из имени файла модуля, за которым следуют спецификаторы, такие как имена классов, имена функций и параметры из параметризации, разделенные символами "::"

### Запуск конкретного теста в модуле

```plaintext
pytest test_mod.py::test_func
```

### Запуск теста по модулю и классу

```plaintext
pytest test_mod.py::TestClass::test_method
```

### Запуск тестов по маркерам

Запустить все тесты помеченные - **@pytest.mark.one_workload**

```plaintext
pytest -m one_workload
```

Запустить все тесты НЕ помеченные - **@pytest.mark.one_workload**

```plaintext
pytest -m "not one_workload"
```

### Запуск тестов команды.

Запустить все тесты, помеченных - **@allure.label("team", "Имя команды")**

```plaintext
pytest --allure-label team='Имя команды'
```

### Запуск тестов из пакетов

Это приведет к импорту pkg.testing и использованию его местоположения в файловой системе для поиска и запуска тестов

```plaintext
pytest --pyargs pkg.testing
```

### Профилирование продолжительности выполнения теста

Чтобы получить список из 10 самых медленных тестов продолжительностью более 1,0 с:

```plaintext
pytest --durations=10 --durations-min=1.0
```

### Запуск UI тестов с отображением браузера

```plaintext
--headed
```

### Запуск UI тестов в замедленном режиме

Между всеми выполняемыми действиями будет задержка в указанное количество миллисекунд

```plaintext
--slowmo 2000
```

### Логирование в проекте

При отладке тестов может помочь логирование уровня DEBUG

```shell
--log-cli-level=DEBUG
```

## Шаблоны запуска тестов

Намного удобнее прописать эти аргументы в шаблон pytest, чтобы они автоматически применялись к каждому запуску. Для этого:
* В навигационном меню PyCharm открываем `Run → Edit Configurations...`
* В открывшемся окне, в левом нижнем углу, нажимаем `Edit Configuration templates...`
* Выбираем `Python Tests → Pytest` 
* Указываем `Working Directory` как каталог проекта
* В `Additional arguments` добавляем те аргументы, которые мы хотим использовать для каждого запуска, на ваш выбор, например:
  * Создавать отчёт по пройденным тестам - `--alluredir allure-results`
  * Перед запуском тестов чистить отчёты - `--clean-alluredir`
  * Показывать браузер, при прогоне UI тестов - `--headed`
  * Замедленный режим, при прогоне UI тестов - `--slowmo 2000`
* Сохраняем шаблон и не забываем, что это - *шаблон*, он не изменит уже существующие конфигурации, применится только к новым созданным.


## Отчёт

### Создание отчёта

Для формирования отчета нужно добавить дополнительные аргументы к запуску pytest:
- `--alluredir allure-results` - директория куда будут складываться результаты прогона в спецификации allure
- `--clean-alluredir` - автоматическая очистка каталога с результатами предыдущего прогона перед следующим запуском

Пример запуска с отчетом:

```plaintext
pytest -m smoke --alluredir allure-results --clean-alluredir
```


### Просмотр отчёта

После запуска тестов в каталоге `alure-results` сохраняется необходимая для формирования отчета информация.
Для просмотра самого отчета нужно его сформировать. Сделать это можно командой `allure serve` (live-режим) или
`allure generate --single-file` (генерация html-файла отчета).


#### allure serve

Просмотр отчета без сохранения

```plaintext
allure serve
```

Отчёт автоматически откроется в браузере.

Если этого не произошло - в консоли можно найти адрес, на котором запустился сервер allure.

Если результаты запуска находятся не в каталоге `allure-results`, то его нужно указать:

```plaintext
allure serve <путь до каталога с результатами запуска>
```


#### allure generate

Генерация и сохранение html-отчета
`allure generate --single-file <путь до каталога с файлами отчета> -o <путь до каталога сформированного отчета>`
