# Настройка окружения

Объяснение скрипта по шагам:
1. Установка менеджера зависимостей **Poetry** (аналогичного встроенному pip, у нас используется **Poetry (version 2.2.1)**)
2. Запуск **Poetry shell** (это запустит оболочку в виртуальной среде.)
3. Установка зависимостей проекта. Это включает установку необходимых пакетов для разработки.
4. Для UI тестов мы используем **playwright** и, чтобы он смог запуститься нужно дополнительно установить
необходимые браузеры.

```sh
pip install poetry==2.2.1
poetry shell
poetry install
playwright install
```
