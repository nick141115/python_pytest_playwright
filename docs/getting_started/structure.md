# Структура проекта

1.	**Autotests** - основной код автотестов.
2.	**Docs** - документация автотестового проекта.

---

- **src** – база автотестов 
  - **constants** – папка, содержащая файлы с константами
  - **pages** – папки с описанием страниц Page, основанных на base_page
- **tests** – файлы с тестами pytest
  - **base/base_test.py** – базовый тестовый класс, от него наследуются все остальные тесты
  - **e2e** – End-to-End автотесты
- **pyproject.toml** – зависимости в проекте, версия автотестов указывается здесь
- **run_tests_and_publish_to_tfs.sh** – скрипт запуска автотестов в один поток из tests/e2e и дальнейшей публикации результатов прогона в тестовый TFS (обычно используется для ночных прогонов)
- **run_tests_right_now.sh** – скрипт запуска автотестов из tests/e2e с большим количеством потоков для быстрого прогона (например, во время рабочего дня)
- **settings_example.py** – файл с переменными окружения
  - для локальной разработки создается файл **settings.py**, который уже и заполняется нужными значениями
