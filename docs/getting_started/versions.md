# Как выставлять версии для изменений в Autotests?

Система обновления версий похожа на Semantic Versioning. Обновлять версии в **pyproject.toml**.
- **MAJOR**
	- Принципиально переработана структура автотестов
	- Был осуществлен переход на другой фреймворк/язык/паттерн проектирования
- **Minor** (feat, refactor)
	- Новые автотесты
	- Изменены текущие автотесты
	- Была поправлена/улучшена логика
- **Patch** (fix)
	- Устранение флаки-тестов, исправление ошибок в коде, маленькие правки т.п.
