# settings.py

Для локальной работы нужно создать и заполнить в папке `Autotests` файл **settings.py**,  
где `settings_example.py` – шаблон такого файла.

| Параметр                           | Описание                                                                                            |
|------------------------------------|-----------------------------------------------------------------------------------------------------|
| `LOGIN`                            | Логин для авторизации                                                                               |
| `PASSWORD`                         | Пароль для авторизации                                                                              |
| `URL`                              | URL сервиса                                                                                         |
| `IGNORE_HTTPS_ERRORS`              | Игнорировать любые ошибки SSL-сертификатов при посещении веб-сайтов                                 |
| `SCREENSHOTS`                      | Делать снимки экрана при выполнении автотестов                                                      |
| `SNAPSHOTS`                        | Сохранять полные слепки состояния DOM (HTML и CSS) для каждого действия                             |
| `SOURCES`                          | Включить исходный код автотестов в файл трассировки                                                 |
| `INIT_SCRIPT`                      | JavaScript-код, который будет выполняться до встроенных скриптов сайта и до загрузки самой страницы |
| `DEFAULT_TIMEOUT`                  | Таймаут для всех действий по умолчанию                                                              |
