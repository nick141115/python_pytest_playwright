# Введение

Репозиторий `r734_autotests` создан для автоматизированных End-to-End тестов сервиса Архитектурный репозиторий (АР).
Основные цели автоматизации тестирования — ускорение самого процесса тестирования, повышение его эффективности и 
воспроизводимости за счет использования специальных инструментов и программного обеспечения.

В проекте применяется Page Object модель. Основные инструменты и технологии: Python, Pytest, Playwright, Allure.
