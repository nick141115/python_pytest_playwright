## Ошибки при запуске
Исключения в python почти всегда имеют говорящие названия и достаточное для понимания описание. 
Так же в выводе об ошибке всегда есть указание на файл и строку в которой было вызвано исключение. 
Практически во всех IDE по этой ссылке можно перейти к самому файлу. 

Ниже описаны наиболее часто возникающие ошибки

### ModuleNotFoundErrors
```
E   ModuleNotFoundError: No module named '<имя модуля>'
```

Отсутствует одна или несколько из используемых в проекте зависимостей (см. [pyproject.toml](../pyproject.toml)).
Если не было подготовлено окружение, то можно пройтись по [этой](getting_started/environment.md) инструкции.

Решение:
- Отсутствуют все модули, отсутствует один или несколько модулей – `poetry install`
