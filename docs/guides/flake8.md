# Линтер flake8

**Flake8** — это популярный **Python-линтер**, который проверяет стиль кода и находит ошибки, объединяя в себе **pycodestyle** (стиль **PEP 8**), **pyflakes** (логические ошибки) и **mccabe** (сложность). Он имеет широкую экосистему плагинов для дополнительных проверок, легко настраивается (например, **max-line-length**, **exclude**), и используется для поддержания единообразия и качества кода.

Установка:

```sh
pip install flake8
```

Чтобы проверить на ошибки все автотесты, нужно запустить из **папки Autotests**:

```sh
flake8
```
