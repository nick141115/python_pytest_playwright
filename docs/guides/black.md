# Форматтер Black

**Black** может привести все виды синтаксических конструкций Python к [единому стилю](https://black.readthedocs.io/en/stable/the_black_code_style/current_style.html).

Установка:

```sh
pip install black
```

Чтобы отформатировать все автотесты и привести их к единому стилю нужно запустить из **папки Autotests**:

```sh
black .
```
