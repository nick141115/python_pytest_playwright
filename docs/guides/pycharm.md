# Настройки и фишки PyCharm

Сюда можно добавлять все, что касается настройки **PyCharm**, интересных особенностей, косяков с версиями и прочее.

### HotKeys

- **Double Shift** – открывается окно поиска по названиям файлов, классов, методов проекта.
- **Ctrl + Shift + F** – открывается окно поиска по содержимому файлов.
- **Ctrl + K** – открывается окно коммита.
- **Ctrl + Shift + K** – открывается окно пуша.

### Languages

Чтобы **PyCharm** не подчеркивал все русские слова волнистой линией и проверял орфографию, нужно скачать словарь русского языка.
Как это сделать:

`File → Settings (Ctrl + Alt + S) → Editor → Natural Languages → + → Русский`

Скачиваем, применяем, наслаждаемся.
